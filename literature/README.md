# Literature Review & Foundational Baselines

This directory archives foundational Morph Attack Detection (MAD) literature analyses, surveying both Single-Image (S-MAD) and Differential (D-MAD) benchmarks.

---

## 📂 Index

1. **[`literature_synthesis.md`](literature_synthesis.md):**
   - Consolidated cross-paper analysis identifying current SOTA failure modes (black-box models, tiny data memorization, feature pathway shortcuts) and outlining the architectural requirements for UID-MAD.
2. **[`paper1_composite_heatmaps.md`](paper1_composite_heatmaps.md):**
   - ViT occlusion heatmaps (Grid + Landmark blocking) and interpretability in face morph detection.
3. **[`paper2_deep_learning_survey.md`](paper2_deep_learning_survey.md):**
   - Deep learning survey across CNNs, GANs, and ViTs, highlighting benchmark drops on NIST FATE and FVC-onGoing.
4. **[`paper3_facenet_hasc_baseline.md`](paper3_facenet_hasc_baseline.md):**
   - Hybrid spatial-frequency baseline (FaceNet 128-d + HASC-Beta + XQDA) and MMPMR vulnerability metrics.
5. **[`paper4_dmad_hybrid_analysis.md`](paper4_dmad_hybrid_analysis.md):**
   - Statistical evaluation under ISO/IEC 30107-3 (APCER, BPCER) and high-pass residual feature analysis.
